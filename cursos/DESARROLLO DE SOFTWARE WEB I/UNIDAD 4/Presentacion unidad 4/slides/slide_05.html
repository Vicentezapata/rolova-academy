Patrón Repository

Consiste en ocultar la lógica de base de datos (Eloquent) detrás de una capa. El controlador no debe saber que usas MySQL.

Sin Repository

User::where('active', 1)->orderBy('name')->get();
Si la BD cambia o la lógica se repite en 5 controladores, toca buscar y copiar código 5 veces.

Con Repository

$this->userRepo->getActiveUsers();
El controlador solo pide datos. No le importa cómo los consigues (Caché, BD o API externa).

Proyecto Libre: Interfaces con Laravel & Blade

Diseña y desarrolla tu propio proyecto web en Laravel enfocado en la implementación de interfaces de usuario con Blade. Deberás crear rutas, controladores, modelos y vistas funcionales que demuestren el dominio de los componentes del framework, presentándolo el día de la evaluación.

Modalidad: Presentación en Vivo El día de la evaluación deberás presentar tu proyecto funcionando y explicar las decisiones técnicas tomadas. La presentación es individual y obligatoria.

Ideas de Proyecto (Elige una o propón la tuya)

El proyecto debe representar un caso real y coherente. Aquí algunos ejemplos:

Tienda / Catálogo
Gestión de Tareas
Agenda de Citas
Biblioteca Digital
Menú de Restaurante
Registro de Alumnos
Fichas de Pacientes
Portafolio Profesional

Requerimientos Técnicos

1. Identificación de Componentes — Rutas (18 pts)

Mínimo 5 rutas definidas en web.phpDeben cubrir las operaciones del proyecto: listar, crear, mostrar detalle, actualizar y eliminar, adaptadas a tu temática elegida.
Verbos HTTP correctosUsar GET, POST, PUT/PATCH y DELETE según corresponda a cada operación.

2. Arquitectura del Proyecto (18 pts)

Estructura de carpetas correctaRespetar la organización de Laravel: app/Http/Controllers/, app/Models/, resources/views/, routes/web.php.
Nombres descriptivosLos archivos, controladores, modelos y vistas deben tener nombres claros y descriptivos que reflejen su función (ej: ProductoController, productos/index.blade.php).

4. Componentes Reutilizables (14 pts)

Componentes Blade reutilizablesCrear al menos un componente reutilizable con Blade: puede ser un layout base (@extends/@yield), un @include parcial (header, footer, card), o un Blade Component.
Paso de datos desde el controlador al componenteLos controladores deben enviar datos a las vistas usando compact(), with() o array asociativo, y los componentes deben recibirlos y renderizarlos correctamente.
// Tip del Profesor: Formas de enviar datos a la vista // Opción 1: compact() return view('productos.index', compact('productos', 'titulo')); // Opción 2: with() return view('productos.index')->with('productos', $productos); // Opción 3: Array asociativo return view('productos.index', [ 'productos' => $productos, 'titulo' => 'Mi Catálogo' ]);
{{-- Tip del Profesor: Reutilizar layouts con Blade --}} {{-- Layout base: resources/views/layouts/app.blade.php --}} <html> <body> @include('partials.header') @yield('contenido') @include('partials.footer') </body> </html> {{-- Vista hija: resources/views/productos/index.blade.php --}} @extends('layouts.app') @section('contenido') @foreach($productos as $producto) <div class="card">{{ $producto['nombre'] }}</div> @endforeach @endsection

5. Interfaces de Usuario — Vistas Blade (18 pts)

Mínimo 5 vistas de usuarioCrear todas las vistas necesarias para cubrir las operaciones del proyecto: listado, detalle, formulario de creación, edición, etc.
Uso de directivas BladeUtilizar directivas como @foreach, @if, @extends, @section, @yield, @include, {{ }} para renderizar datos dinámicos.
Estilos aplicadosLas vistas deben tener estilos CSS aplicados (pueden ser básicos) que permitan una presentación visual clara y organizada de la información.

Guía para la Presentación

Demostración funcionalMostrar el proyecto corriendo en local (php artisan serve) y navegar por todas las funcionalidades implementadas.
Explicación de la arquitecturaExplicar la estructura del proyecto: rutas definidas, métodos del controlador, modelo estático y cómo se conectan con las vistas Blade.
Defensa técnicaEstar preparado para responder preguntas sobre las decisiones de diseño, flujo de datos y estructura MVC utilizada.
Importante Si el alumno no puede explicar o defender su código durante la presentación, se aplicará una penalización en la nota final. El proyecto debe ser de autoría propia.

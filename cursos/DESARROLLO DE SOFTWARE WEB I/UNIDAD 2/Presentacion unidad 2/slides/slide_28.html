Autenticación: Inicio de Sesión

Para autenticar, construimos un Controlador de Inicio de Sesión usando los estándares de Laravel (Indicador 2).

LoginController.php
public function login(Request $request) { $credenciales = $request->validate([ 'email' => 'required|email', 'password' => 'required' ]); if (Auth::attempt($credenciales)) { $request->session()->regenerate(); return redirect()->intended('/dashboard'); } return back()->withErrors([ 'email' => 'Credenciales incorrectas.', ]); }
1
Validación

Siempre validar los datos del Request entrante.

2
Auth::attempt()

Busca el email y verifica que el hash coincida con la contraseña ingresada de forma segura.

3
Session Fixation

session()->regenerate() evita vulnerabilidades de robo de sesión.

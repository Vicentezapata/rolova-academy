Eloquent: CRUD sin SQL

Las 4 operaciones fundamentales en PHP elegante.

CREATE — Crear
Proyecto::create([ 'nombre' => 'Tech Solutions', 'monto' => 15000, 'estado' => 'activo', 'fecha_inicio' => '2024-03-01', ]);
READ — Leer
Proyecto::all(); Proyecto::find(1); Proyecto::where('estado','activo') ->orderBy('nombre') ->get();
UPDATE — Actualizar
$p = Proyecto::find(1); $p->update(['estado'=>'inactivo']); // O directamente: $p->estado = 'inactivo'; $p->save();
DELETE — Eliminar
$p = Proyecto::find(1); $p->delete(); // Una sola linea: Proyecto::destroy(1);

Conceptos Clave de la Unidad

Migraciones

El sistema de control de versiones para la base de datos. Permite crear y modificar tablas mediante código PHP, sin necesidad de escribir sentencias SQL directas.

Eloquent ORM

Mapeo Objeto-Relacional que proporciona una interfaz sencilla e intuitiva para interactuar con las tablas de tu base de datos a través de modelos de PHP.

Cifrado & Autenticación

Encriptación segura de contraseñas de usuario (hashing) antes de guardarlas, y autenticación basada en tokens JWT para APIs sin estado.

Seeders & Factories

Poblamiento automatizado de bases de datos con datos sintéticos y realistas mediante la biblioteca Faker. Excelente para pruebas de desarrollo.

Comandos Artisan Esenciales

php artisan make:model Proyecto -mcf

Modelo Completo

Genera el modelo en app/Models/, junto con su archivo de migración (-m), controlador resource (-c) y factory (-f) en un único paso.

php artisan migrate

Ejecutar Migraciones

Aplica todas las migraciones pendientes que no hayan sido registradas en la tabla 'migrations' de la base de datos.

php artisan migrate:rollback

Deshacer Cambios

Revierte el último lote de migraciones que fue ejecutado. Útil para corregir errores de estructura recientes.

php artisan migrate:fresh --seed

Reinicio Completo

Elimina todas las tablas de la base de datos, vuelve a aplicar todas las migraciones desde cero y ejecuta los seeders de prueba.

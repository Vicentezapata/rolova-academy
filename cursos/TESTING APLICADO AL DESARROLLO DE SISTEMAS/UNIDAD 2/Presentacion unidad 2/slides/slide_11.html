TC-001

¿Qué es un Test Case?

Un conjunto documentado de condiciones bajo las cuales se determinará si una aplicación cumple sus especificaciones. Debe ser tan preciso que alguien nuevo pueda ejecutarlo sin ambigüedad. Cada campo tiene un propósito crítico: omitir uno invalida el caso.

Campo 01
ID / Título
Identificador único y nombre descriptivo. Permite referenciar el caso en la RTM, defectos y reportes.
TC-001: Validar login exitoso con credenciales correctas — Módulo de autenticación.
Campo 02
Precondiciones
El estado exacto del sistema ANTES de ejecutar. Sin esto, el resultado no es reproducible.
El usuario 'admin' existe en BD con estado Activo. El navegador está en /login.
Campo 03
Pasos (Steps)
Acciones explícitas, secuenciales y atómicas. Cada paso = una acción. Sin interpretación posible.
1. Ingresar user 'admin'. 2. Ingresar pass '1234'. 3. Click en 'Entrar'.
Campo 04
Resultado Esperado
La validación que define el ÉXITO. Verbo + objeto + estado final. Debe ser 100% verificable.
El sistema redirige a /dashboard y muestra el mensaje "Bienvenido Admin".
Campo 05
Datos de Prueba
Variables, archivos o configuraciones específicas necesarias. Deben ser versionados.
user: 'admin', pass: '1234', env: staging-v2.

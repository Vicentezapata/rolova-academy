ANEXO Glosario Maestro de Términos 2/5

Términos, acrónimos y definiciones operativas clave para aprobar la certificación GH-500.

TérminoDefinición Operativa
RulesetRegla de gobierno (rama/etiqueta/push) que puede exigir protección de merge por code scanning.
Delegated bypassFlujo de aprobación para saltarse push protection.
Delegated alert dismissalFlujo de aprobación para descartar alertas ('Prevent direct alert dismissals').
SARIFStatic Analysis Results Interchange Format, estándar OASIS JSON para resultados de análisis estático.
CodeQLMotor de análisis semántico de GitHub: trata el código como datos y ejecuta consultas (QL) sobre una base de datos.
Tip de examen: Diferenciar entre Code Security y Secret Protection es vital para preguntas de licenciamiento.
